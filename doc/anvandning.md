# Användning & Filstruktur

## Starta programmet

* **Terminalläge:** `python main.py`
* **Fönsterläge:** `python windowmain.py`
* **Konfiguration:** `python config.py`

## Projektets filer

```
main.py                             Kör hjulet i terminalen.
windowmain.py    Kör hjulet med hjälp av fönster på skärmen.
windowdef.py              En fil med funktioner för fönster.
config.py       Verktyg för att lägga till och ta bort namn.
common.py           Funktioner för terminalen och data.json.
data.json                  Sparar information om deltagarna.
```
