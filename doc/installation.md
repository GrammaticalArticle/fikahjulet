# Installation & Setup

## Vad behövs?

* **Python 3.6+**
* **colorama**
* **Pillow**
* **pytest-cov** (för tester)

## Installera

1. **Klona repot:**
   ```bash
   git clone https://github.com/GrammaticalArticle/fikahjulet
   cd fikahjulet
   ```

2. **Installera dependencies:**
   ```bash
   pip install colorama Pillow pytest-cov
   ```

3. **Lägg till deltagare och avatarer:**
   * Kör `python config.py` eller ändra direkt i `data.json`.
   * Lägg valfria bilder i en `avatar/`-mapp döpta till `avatar1.png`, `avatar2.png` osv.
